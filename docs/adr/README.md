# ADR — 설계 결정 기록

구조적 선택을 할 때마다 한 장씩 남긴다. **"왜 이렇게 했나"의 원본**이 되는 문서다.

파일명: `NNN-짧은-제목.md` (예: `001-왜-단일-프롬프트가-아니라-그래프인가.md`)

템플릿:

```markdown
# NNN. {결정 제목}
- 상태: 제안 / 채택 / 폐기 / 대체됨(→ NNN)
- 날짜: YYYY-MM-DD

## 맥락
어떤 문제 앞에 있었는가.

## 선택지
- A) ... — 장/단
- B) ... — 장/단

## 결정
무엇을 골랐는가.

## 트레이드오프
무엇을 포기했는가. **이 항목을 비워두지 않는다.**

## 되돌리는 조건
어떤 관측이 나오면 이 결정을 뒤집는가.
```

설계 문서 §1에 근거가 적힌 4건은 ADR로 옮겨둘 것:
그래프 분리 / 도구 호출 / 앵커 검색 / 재채점 상한 2회.
