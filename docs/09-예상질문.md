# 예상 질문

이 프로젝트가 **답할 수 있어야 하는 기술 질문** 목록.
답을 여기 적어두지 않는다 — 답은 설계 문서·ADR·측정 결과에 있어야 하고,
없으면 그건 문서가 부족한 것이다.

각 질문 옆의 경로가 **답이 있는 곳**이다. 비어 있으면 아직 답할 수 없는 상태다.

## 아직 답할 수 없는 것

정직하게 적어둔다. 답이 생기면 위 표로 옮긴다.

- **측정 결과가 없다** — 베이스라인 실측 전
- **IAA를 모른다** — 회귀 임계치 0.60에 근거가 없다
- **홀드아웃을 나누지 않았다** — 골든셋 과적합을 막을 장치가 없다
- **실패 사례 분석이 비어 있다** — `failures/`가 비어 있으면 한계를 말할 수 없다
