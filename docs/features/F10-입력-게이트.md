# F10. 입력 게이트 (전처리 · 사전 라우팅)

| | |
|---|---|
| 상태 | **미구현** |
| 단계 | T1 |
| 예정 코드 | `src/rubriq/graph/nodes/preprocess.py` · `route.py` |
| 의존 | F09 그래프 상태 |

## 문제

**채점할 수 없는 입력에 LLM을 호출하는 건 낭비이고 위험하다.**
50단어짜리 글, 한국어로 쓴 글, 과제와 무관한 글에 "Grammar 3점"을 주면
숫자는 나오지만 의미가 없다.

## 계약

```
전처리:     essay → normalized_text · word_count · language
사전 라우팅: → early_return: EarlyReturnReason | None
```

```python
class EarlyReturnReason(StrEnum):
    TOO_SHORT      = "too_short"       # 분량 미달
    NOT_ENGLISH    = "not_english"     # 비영어
    OFF_TOPIC      = "off_topic"       # 주제 이탈
    EMPTY          = "empty"
```

## 설계 — 전처리

| 처리 | 방식 | 왜 |
|---|---|---|
| 공백 정규화 | 연속 공백·줄바꿈 축약 | 인용 대조(F01)와 일관되게 |
| 유니코드 정규화 | NFC | 같은 글자가 다르게 비교되는 것 방지 |
| 언어 판별 | 규칙 기반 (ASCII 비율) 우선 | LLM 호출 없이 결정적으로 |
| 단어 수 | 공백 분할 | 단순함이 재현성을 준다 |

**원문을 파괴하지 않는다.** `normalized_text`는 별도 필드이고 `essay.text`는 그대로 둔다 —
근거 인용 대조는 원문 기준이어야 한다.

## 설계 — 사전 라우팅

```
word_count < 50        → TOO_SHORT
ascii_ratio < 0.7      → NOT_ENGLISH
(주제 이탈)             → 별도 판단 필요
```

## 핵심 결정 1 — 임계값은 설정으로 뺀다

`min_word_count=50`은 근거 없는 값이다. 골든셋 분포를 보고 조정한다.
지금 하드코딩하면 나중에 못 고친다.

## 핵심 결정 2 — 주제 이탈은 보류한다

주제 적합성 판단은 **과제 지시문(`essay.prompt`)이 있어야** 가능하다.
ELLIPSE 골든셋에 지시문이 없으면 이 분기는 동작할 수 없다.
데이터를 본 뒤 결정하고, 그때까지는 **분기 자체를 넣지 않는다.**

> 동작하지 않는 분기를 그래프에 그려두면 다이어그램이 거짓말을 한다.

## 핵심 결정 3 — 조기 반환도 유효한 결과다

`early_return`이 서면 점수 없이 `needs_human_review`로 반환한다.
**0점을 주지 않는다.** 분량 미달은 "못 썼다"가 아니라 "채점 대상이 아니다"이다.

## 실패 모드

| 상황 | 처리 |
|---|---|
| 빈 입력 | 스키마(F01)에서 이미 거부 |
| 경계값 (49단어) | 임계값 로그에 남기고 조기 반환 |
| 언어 판별 오탐 | ASCII 비율은 거칠다 — 오탐률을 골든셋으로 측정 후 조정 |

## 측정

골든셋에서 **조기 반환 비율**. 이게 높으면 임계값이 잘못됐거나 데이터가 안 맞는 것이다.
오탐(채점 가능한 글을 걷어냄)은 미탐보다 비싸다.
