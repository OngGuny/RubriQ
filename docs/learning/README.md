# 학습노트

이 프로젝트를 하면서 **처음 만난 개념**을 정리하는 곳.

## 왜 따로 두는가

`docs/00-설계.md`나 `docs/01-루브릭.md`는 **결정을 적는 문서**다. "무엇을 할 것인가"가 들어간다.
여기는 **이해를 적는 문서**다. "그게 무슨 뜻인가"가 들어간다. 둘을 섞으면 설계 문서가 교과서가 되고,
정작 결정이 안 보인다.

설명할 수 있는 것과 이해한 것은 다르다. 바탕이 없으면 설명은 암기가 되고,
"그게 왜 그런데요?" 한 번에 무너진다. 여기는 그 바탕을 적는 곳이다.

## 쓰는 규칙

1. **모르는 채로 넘어가지 않는다.** 구현하다 모르는 단어가 나오면 여기에 항목을 만든다.
   당장 안 써도 제목만이라도 목록에 올린다.
2. **내 문장으로 다시 쓴다.** 정의를 옮겨 적는 건 이해가 아니다.
   "그래서 이 프로젝트에서 이게 왜 필요한가"를 반드시 한 줄 붙인다.
3. **예시를 넣는다.** 추상적 정의만 있으면 다음 주에 다시 읽어도 모른다.
4. 다 안 채워도 된다. 목록의 `미작성`은 부채가 아니라 **앞으로 배울 것 목록**이다.
