# 루브릭 정의

채점 프롬프트와 골든셋이 공유하는 기준. **이 문서가 프롬프트의 원본**이고,
`src/rubriq/prompts/templates/`의 루브릭 블록은 여기서 파생된다.

> 루브릭이 **무엇인지**는 [`docs/learning/01-루브릭.md`](learning/01-루브릭.md) 참조.
> 이 문서는 개념 설명이 아니라 **우리가 쓸 기준의 확정본**이다.

## 원본 대조 완료 (2026-09-12)

이 루브릭은 **ELLIPSE 공식 루브릭(`ELL_Rubrics.docx`)과 대조해 수정을 마쳤다.**
골든셋의 정답 점수는 ELLIPSE 애너테이터가 그 루브릭으로 매긴 값이므로,
기준이 어긋나면 QWK 하락을 모델 성능 문제로 오진하게 된다 (ADR 001).

대조에서 **4건의 실질적 차이**를 찾아 전부 원본 기준으로 고쳤다 —
상세 내역은 하단 「원본 대조 기록」에 있다.

- 출처: https://github.com/scrosseye/ELLIPSE-Corpus (`ELL_Rubrics.docx`)
- 상태: **검증됨**

### 서술어를 원문 그대로 옮기지 않는 이유

공식 루브릭은 CC BY-NC-SA 4.0 아래 있다. 원문 서술어를 이 저장소에 복제하면
ShareAlike 조항이 걸린다. 따라서 **기준은 원본에 정확히 맞추고 문장은 직접 썼다.**
근거는 `eval/golden/LICENSE.md` 참조.

## 점수 척도

1~5점 정수. 높을수록 능숙하다.

| 점수 | 대략적 의미 |
|---|---|
| 5 | 해당 능력을 일관되게, 자연스럽게 구사한다 |
| 4 | 대체로 능숙하나 부분적으로 흔들린다 |
| 3 | 기본은 되나 오류·어색함이 눈에 띄게 섞인다 |
| 2 | 의미 전달은 되나 오류가 이해를 자주 방해한다 |
| 1 | 해당 능력이 거의 드러나지 않거나 이해를 심하게 방해한다 |

### 반올림 정책 (측정에 직접 영향)

ELLIPSE 원본 점수는 **1.0~5.0을 0.5 단위**로 매긴다. QWK는 정수 라벨을 전제하므로 변환이 필요하다.

- **기본 정책**: 정답 점수를 `round-half-up`으로 정수화한다 (2.5 → 3).
- **문제**: 예측은 처음부터 정수인데 정답만 반올림하므로 **오차가 비대칭**으로 들어간다.
  2.5짜리 에세이를 모델이 2로 예측하면 실제 오차는 0.5인데 지표상 1로 계산된다.
- **대응**: 정수 점수만 가진 부분집합으로 QWK를 한 번 더 계산해 **민감도**를 본다.
  두 값이 크게 벌어지면 반올림이 지표를 왜곡하고 있다는 뜻이므로 정책을 재검토한다.
- 이 민감도 수치를 `docs/results/01-baseline.md`에 같이 기록한다.

> 요점: 0.5 단위 라벨을 정수 지표에 넣을 때 생기는 왜곡을 먼저 측정해,
> **지표 자체를 신뢰할 수 있는지**부터 확인한다.

## 항목별 정의

6개 항목은 **독립적으로** 채점한다. 한 항목의 낮은 점수가 다른 항목을 끌어내리면 안 된다
([설계 문서 §1](00-설계.md) — 항목 간 점수 오염이 분리 호출의 이유다).

### 1. Cohesion — 응집성

문장과 문단이 논리적으로 연결되어 글이 하나의 흐름을 이루는가.
**내용의 좋고 나쁨이 아니라 연결의 문제다.**

| 점수 | 기준 |
|---|---|
| 5 | 문단 구조가 명확하고 전환이 자연스럽다. 연결어가 다양하고 정확하게 쓰인다 |
| 4 | 전반적으로 잘 연결되나 일부 전환이 갑작스럽다 |
| 3 | 기본적인 연결은 있으나 연결어가 단조롭거나(and, but 반복) 문단 구분이 흐리다 |
| 2 | 문장들이 나열에 가깝다. 논리적 순서를 따라가기 어려운 구간이 있다 |
| 1 | 연결이 거의 없어 개별 문장으로 읽힌다 |

### 2. Syntax — 문장 구조

문장을 얼마나 정확하고 다양하게 구성하는가.

| 점수 | 기준 |
|---|---|
| 5 | 단문·복문·복합문을 목적에 맞게 구사한다. 구조적 오류가 거의 없다 |
| 4 | 다양한 구조를 시도하며 대체로 정확하다. 복잡한 문장에서 간혹 흔들린다 |
| 3 | 단순한 구조 위주. 복문 시도 시 오류가 나타난다 |
| 2 | 문장 구조가 단조롭고 어순·구조 오류가 빈번하다 |
| 1 | 문장 경계가 불분명하거나 구조가 무너져 있다 |

### 3. Vocabulary — 어휘

어휘의 범위·정확성·적절성. **주제 관련 용어(topic-related terms)와
덜 흔한 어휘를 쓰는지도 포함한다.**

| 점수 | 기준 |
|---|---|
| 5 | 폭넓은 어휘를 유연하게 써서 정밀한 의미를 전달한다. 주제 관련 용어와 덜 흔한 낱말을 능숙하게 쓴다. 부정확한 용례가 거의 없다 |
| 4 | 어휘 범위가 충분하다. 주제 관련 용어를 쓰며 드물게 부정확한 선택이 있다 |
| 3 | 주제에 필요한 어휘 범위가 최소한이다. 미묘한 의미 차이를 살리지 못하고, 주제 관련 용어는 간헐적으로만 나온다. 덜 흔한 어휘를 시도하나 부정확함이 섞인다 |
| 2 | 어휘가 제한적이고 낱말 선택·형태 통제가 약하다 |
| 1 | 제한된 어휘를 부적절하게 쓰는 일이 잦다. 주제 관련 용어를 쓰려는 시도가 거의 없다 |

> **원본 대조로 고친 부분**: 공식 루브릭은 **주제 관련 용어 사용**을 명시적으로 본다.
> 원래 이 항목을 누락했고, 게다가 아래 규칙 4번("주제 적합성은 채점 대상이 아니다")과
> 충돌했다. 규칙 4번도 함께 수정했다.

### 4. Phraseology — 관용 표현

**Vocabulary가 낱말이라면 여기는 낱말의 결합이다.** 세 종류를 본다 —
관용구(idiom), 연어(collocation), **어휘 다발(lexical bundle)**.

| 점수 | 기준 |
|---|---|
| 5 | 관용구·연어·어휘 다발을 다양하게 유연히 써서 정밀하고 미묘한 의미를 전달한다. 사소한 부정확함이 드물다 |
| 4 | 여러 표현을 쓰며 대체로 자연스럽다. 간혹 어색한 결합이 있다 |
| 3 | 관용구·연어·어휘 다발을 쓰는 것이 보이나 다양성이 부족하다. 눈에 띄는 반복과 오용이 있다 |
| 2 | 부자연스러운 결합과 반복이 잦다 |
| 1 | **암기한 청크**나 단순한 구 패턴이 지배적이다. 표현의 반복과 오용이 많다 |

> **원본 대조로 고친 부분**: 공식 루브릭은 **어휘 다발(lexical bundle)** 과
> 1점대의 **암기 청크(memorized chunks)** 를 명시한다. 원래 둘 다 누락했다.
> 참고 — 원본 용어 정의: 어휘 다발은 영어에서 흔하지만 관용적이지 않은 다어 단위("There is"),
> 청크는 개별 낱말 뜻을 모르고 외운 단위("How are you").

### 5. Grammar — 문법

시제·일치·관사·전치사 등 문법 규칙의 정확성.

| 점수 | 기준 |
|---|---|
| 5 | 문법과 용법을 장악하고 있다. 오류가 없거나 극히 드물다 |
| 4 | 오류가 적다 |
| 3 | 오류가 어느 정도 있다 |
| 2 | 오류가 많다 |
| 1 | 글 전체에 오류가 퍼져 있다 |

> **원본 대조로 고친 부분**: 원래 "이해를 방해하는가"를 기준으로 썼으나,
> 공식 루브릭의 Grammar는 **오류의 양만** 본다. 의사소통 저해 여부는
> 별도의 Overall(홀리스틱) 항목이 담당하며 우리는 그 항목을 채점하지 않는다.
> 이해도 기준을 Grammar에 섞으면 애너테이터와 다른 축으로 채점하게 된다.

> **도구 연계**: `grammar_check`(LanguageTool)가 뽑은 오류 목록을 컨텍스트로 넣는다.
> 오류 **개수를 세는 건 도구**가 하고, 그 오류가 이해를 얼마나 방해하는지 **판단은 LLM**이 한다
> ([설계 문서 §1](00-설계.md) — 결정적 도구와 LLM 판단의 역할 분리).

### 6. Conventions — 표기 관습

**철자 · 대소문자 · 구두점.** 이 세 가지만 본다.

| 점수 | 기준 |
|---|---|
| 5 | 표기 규범을 일관되게 지킨다. 철자·대소문자·구두점 오류가 없거나 무시할 수준이다 |
| 4 | 오류가 드물다 |
| 3 | 표기 규범 사용이 발달 중이다. 철자·대소문자·구두점 오류가 때때로 주의를 흩뜨린다 |
| 2 | 오류가 잦다 |
| 1 | 표기 규범 사용이 최소한이다. 철자·대소문자·구두점 오류가 글 전체에 퍼져 있다 |

> **원본 대조로 고친 부분**: 원래 "문단 나누기"를 포함했으나 공식 루브릭의
> Conventions는 철자·대소문자·구두점 셋뿐이다. 문단 구성은 **Cohesion** 항목이 담당한다.

## 채점 시 지켜야 할 규칙

프롬프트에 그대로 반영한다.

1. **본문 인용 필수.** 모든 점수에 근거가 되는 본문 구절을 인용한다.
   인용 없는 점수는 스키마가 거부한다 (`DimensionScore.evidence` min_length=1).
   인용은 **원문에 실재해야** 한다 — `ungrounded_evidence()`가 대조한다.
2. **항목 독립.** 다른 항목의 점수를 근거로 삼지 않는다.
   "문법이 나쁘므로 어휘도 낮게" 같은 추론을 금지한다.
3. **분량으로 벌하지 않는다.** 짧다는 이유만으로 감점하지 않는다.
   분량 미달은 사전 라우팅에서 조기 반환으로 처리한다.
4. **글의 내용 품질은 채점 대상이 아니다.** 6개 항목 모두 *언어 능력* 지표다.
   주장이 설득력 있는지, 논거가 타당한지는 보지 않는다.
   내용이 과제를 완전히 벗어났으면 사전 라우팅에서 분기한다.
   **단, Vocabulary는 예외적으로 '주제 관련 용어를 쓰는지'를 본다** —
   이건 내용 평가가 아니라 어휘 범위 평가다 (공식 루브릭 기준).
5. **ESL 학습자 기준.** 원어민 기준이 아니라 영어 학습자 기준으로 본다.
   L1 간섭에서 오는 어색함을 과도하게 벌하지 않는다.

### 6개 중 4개가 어긋나 있었다

이게 ADR 001이 예상한 리스크의 실측값이다. 대조를 건너뛰었다면:

- Grammar는 **다른 축으로 채점**됐을 것이다. 오류가 많아도 이해되는 글에
  내 루브릭은 3점을, 애너테이터는 2점을 줬을 것이다.
- Conventions는 문단 구성까지 반영해 Cohesion과 **상관이 인위적으로 높아졌을** 것이고,
  F14 일관성 검증의 모순 규칙이 오탐을 냈을 것이다.
- 그리고 그 하락을 **프롬프트나 모델 문제로 오진**해 시간을 썼을 것이다.

> 낮은 QWK의 원인은 셋이다 — 모델이 못 하거나, 프롬프트가 나쁘거나,
> **애초에 다른 기준으로 채점하고 있거나.** 세 번째를 먼저 배제했다.

### 아직 안 한 것

- 원본에는 **Overall(홀리스틱)** 항목이 하나 더 있다. Kaggle 대회 데이터는
  분석적 6항목만 제공하므로 채점하지 않는다. 이 항목이 "의사소통 저해" 기준을 담당한다.
- 애너테이터 간 일치도(IAA)를 모른다. 원본 저장소의
  `ellipsis_raw_rater_scores_anon_all_essay.zip`에 개별 평정이 있어 **계산 가능하다**.
  이걸 구하면 "QWK 0.6이 좋은 건가"에 답할 수 있고, 회귀 임계치의 근거가 생긴다.
