## 2026-09-11 — F08 Langfuse 관측

- **한 것**: `observability/langfuse.py` — `TracedLLM` 데코레이터(`StructuredLLM` 프로토콜 그대로 구현), contextvar로 프롬프트 메타데이터 전달, 모든 관측 실패를 삼킴. 테스트 22건(총 143건).
- **인프라**: Langfuse v2 → **v4**. SDK 4.x가 v2 서버와 응답 스키마부터 불일치 ([ADR 004](adr/004-Langfuse-v4로-올리고-SDK를-맞춘다.md)). 컨테이너 2개 → 6개. 헤드리스 초기화로 키 자동 생성.
- **검증**: 채점 트레이스가 ClickHouse까지 도달 확인 (`grade:e-smoke-001` + generation $0.00704).
- **밟은 함정 2건**:
  - `.env`에 키가 생기자 **단위 테스트가 실제 Langfuse를 오염**시킴 → autouse fixture로 격리, 전후 이벤트 수로 검증

- **미완**: 프롬프트를 Langfuse에 등록하지 않음. F08의 완료 조건은 "트레이스로 원인을 찾았다"이며 아직 미달.
