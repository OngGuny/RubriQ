## 2026-09-13 — 💰 비용 게이트 · 실측 전 재점검

- **한 것**: 유료 경로 전수 조사 → 2개(`run_eval.py`, `pytest -m regression`)에 차단 장치. `eval/preflight.py`(비용 추정 + 확인 프롬프트), `--dry-run`(키 없이 비용만), `RUBRIQ_ALLOW_PAID=1` 오프트인. 테스트 18건 추가(총 164건). 전체 목록은 [`docs/COSTS.md`](COSTS.md).
- **실측 전 재점검에서 버그 4건** (전부 호출 없이 발견):
  1. **`.env`의 키가 SDK에 전달되지 않았다** — pydantic-settings는 `.env`, SDK는 `os.environ`. 생성은 성공하고 호출 시점에 인증 실패하는 구조였다. → 설정에서 명시 전달 + 생성 시점 차단
  2. **한국어 내부 주석이 모델에게 전송됐다** — Pydantic이 클래스 docstring을 JSON 스키마 `description`에 넣는다. 그중 "범위를 벗어난 값을 관측하고 싶다"는 범위 이탈을 권하는 것으로 읽힐 수 있었다. → 모델용 영어로 교체, 설계 메모는 `#` 주석으로
  3. **`run_eval.py` 기본 프롬프트가 v1**이었다 — 원본 대조를 통과한 v2가 아니라 검증 전 판본으로 돌게 돼 있었다
  4. **비용을 과소추정**했다 — 단어 수 기반 추정이 마크다운에서 실제의 60%. → `max(단어기반, 문자기반)`으로 보수화
- **검증**: 게이트 무력화 뮤테이션으로 정확히 5건 깨짐 확인. 기본 `pytest` 실행이 Langfuse 이벤트를 늘리지 않음 확인(59→59).
- **잔여 위험**: 애드혹 스크립트(`SinglePromptGrader()` 직접 생성)는 게이트를 우회한다. 자동 차단은 키 부재 시 `MissingCredentials`뿐. 💰 마커와 문서로만 표시했다.
- **다음**: **LLM API 키.** `--dry-run` 기준 50건 $2.77~$7.77, 25~50분(순차). 5건 먼저 실측해 역산 권장.
